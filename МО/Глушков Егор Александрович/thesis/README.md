## Определение кода Голланда по результатам психометрических тестов личности на основе методов машинного обучения в условиях неполноты информации 

**Ключевые слова:** Модель Голланда RIASEC, ансамблевые методы, методы восстановления данных, многоцелевая регрессия, классификация, ранжирование, вычислительная психология личности, профориентация, психометрические тесты личности

### Аннотация

Многие аспекты успешности человека зависят от корректного выбора карьерного пути, соответствующего его личностным предпочтениям и социально-профессиональной направленности. Исходя из признанной роли модели Голланда RIASEC в профориентации, исследование направлено на разработку моделей, которые по результатам других психометрических тестов смогут автоматически восстанавливать профиль RIASEC и тем самым повысить доступность и точность онлайн-профориентации. Целью работы является автоматизация процесса профориентации посредством разработки инструмента для предсказания кода Голланда по неполным результатам психометрических тестов с использованием методов машинного обучения. Для восстановления пропусков в данных применены множественная иммутация (MICE) и низкоранговая мягкая матричная аппроксимация (Soft Impute), для уменьшения размерности — метод главных компонент (PCA). Для прогнозирования профиля Голланда использовались подходы многоцелевой регрессии, многоклассовой и многометочной классификации, а также списочное ранжирование; в качестве базовых моделей задействованы классические алгоритмы машинного обучения и нейросетевые модели. Взвешенное ансамблирование было реализовано через оптимизацию весов при помощи генетических алгоритмов (GA), роя частиц (PSO), квадратичной оптимизации (QP) и расчёта вектора Шэпли. При работе на полных данных наилучший результат обеспечил ансамбль регрессоров со множественными выходами с PSO-оптимизацией весов (C-индекс = 11.663), тогда как лучшая из одиночных базовых моделей — Lasso-регрессия — показала C-индекс = 11.175 . На восстановленных с помощью низкоранговой аппроксимации данных максимальный C-индекс (10.74) был достигнут также PSO-ансамблем регрессоров. В ходе работы было создано веб-приложение на платформе R Shiny с интегрированной PSO-ансамблевой моделью для автоматизации профориентации на основе предсказания кода Голланда.

## Determination of the Holland Code based оn the results of psychometric personality tests using machine learning methods in the presence of incomplete information 

**Keywords:** Holland RIASEC model, ensemble methods, data imputation, multitarget regression, classification, learning-to-rank, personality computing, career guidance, psychometric personality tests

### Abstract

Many aspects of a person’s success depend on the correct choice of a career path that corresponds to their personality preferences and socio-professional orientation. Given the recognized role of the Holland RIASEC model in career guidance, this research is aimed at developing models that, based on the results of other psychometric personality tests, can automatically reconstruct the RIASEC profile and thereby increase the accessibility and accuracy of online career guidance. The aim of this work is to automate the career guidance process by developing a tool for predicting the Holland code from incomplete psychometric personality test results using machine learning methods. For data imputation, multiple imputation by chained equations (MICE) and low-rank Soft Impute matrix approximation were used; for dimensionality reduction, principal component analysis (PCA) was applied. To predict the RIASEC profile, approaches of multitarget regression, multiclass and multilabel classification, and learning-to-rank were used; classical machine learning algorithms and neural network models served as base learners. Weighted ensemble methods were implemented by optimizing model weights using genetic algorithms (GA), particle swarm optimization (PSO), quadratic optimization (QP), and Shapley value computation. When working on the complete data, the best result was provided by the multioutput regression ensemble with PSO weight optimization (C-index = 11.663), while the best single base model, Lasso regression, achieved a C-index of 11.175. On data imputed via low-rank matrix approximation, the maximum C-index (10.74) was also attained by the PSO-regressor ensemble. During this work, a web application was created on the R Shiny platform with an integrated PSO-based ensemble model for automating career guidance based on predicting the Holland code.
